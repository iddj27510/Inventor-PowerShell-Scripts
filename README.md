## Overview

This repository contains 6 PowerShell scripts for Autodesk Inventor automation,
system verification, and project management.

## Scripts

1. **PS-01: Inventor Installation Verifier** - Check Inventor installation
2. **PS-02: Batch File Health Check** - Check file health
3. **PS-03: License Usage Monitor** - Monitor Inventor licenses
4. **PS-04: Project Backup Script** - Backup Inventor projects
5. **PS-05: GitHub Repository Creator** - Create GitHub repositories
6. **PS-06: VS 2026 Installation Verifier** - Check VS 2026 setup

---

## Requirements

- PowerShell 5.1 or PowerShell 7
- Windows 10 or 11
- GitHub CLI (for PS-05)
- FlexNet License Manager (for PS-03)
